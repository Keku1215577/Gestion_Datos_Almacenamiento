# StoreSys

Sistema web de gestión de inventario y almacenamiento.

## Enfoque

Proyecto práctico orientado a desarrollo web y representación de información operativa.

## Funcionalidades principales

- Dashboard con KPIs.
- Gestión de inventario.
- Movimientos de almacén.
- Proveedores.
- Ubicaciones.
- Alertas de stock.
- Reportes.

## Stack

HTML5 · CSS3 · JavaScript vanilla

## Documentación

[Ver documentación del proyecto](./storesys/README.md)

## Ejecución

Abrir [`storesys/index.html`](./storesys/index.html) en un navegador moderno.

Este proyecto complementa mi portafolio mostrando desarrollo frontend, organización modular de código, interfaces de negocio, dashboards y preparación de información para futuras integraciones con APIs y bases de datos.
